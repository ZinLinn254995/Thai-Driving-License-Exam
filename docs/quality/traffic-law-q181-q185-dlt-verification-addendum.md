## Q181 — Chest pain suspected to be heart-related
- Current keyed answer: “No, in any case.”
- Finding: The safety advice not to drive while experiencing unexplained chest pain with possible cardiac cause is prudent. However, “in any case” is broad if read as a permanent ban after evaluation/recovery. The question is best understood as asking whether the person should drive while the concerning symptom is present.
- Myanmar translation: Broadly aligned with English; “မည်သည့်အခြေအနေတွင်မဆို” conveys the same absolute scope.
- Status: KEY REASONABLE for the immediate symptomatic situation; wording is overly broad if interpreted as a permanent restriction.

## Q182 — Brain cancer

## Q183 — Parkinson's disease / shaking hands
- Current keyed answer: Should not drive.

- Myanmar translation: Meaning broadly matches English, though the Thai parenthetical “มือสั่น” is simplified; Parkinson's disease is not defined solely by hand tremor.
- Status: MANUAL REVIEW — likely oversimplified; no edit made.
