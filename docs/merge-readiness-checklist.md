# Merge readiness: website quality and release preparation

This checklist covers app quality, accessibility, reliability, SEO, and release readiness only. Question/answer content, translations, traffic-sign-to-image matching, and asset licensing are explicitly reserved for a separate data-audit branch and are not tasks for this branch. This checklist does not authorize merging this branch into `main`.
