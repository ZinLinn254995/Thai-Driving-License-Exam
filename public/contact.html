Contact and Report an Issue

To report an incorrect traffic-sign image, a question or answer issue, a translation problem, an accessibility concern, or a privacy/copyright concern, please open an issue in the project repository.

Open a GitHub issue for Thai Drive Exam

Please include the question number or page URL and describe the problem. Do not post private personal information in a public issue. If the repository’s issue tracker is unavailable, check the project page for another contact method.
